# Royal Smash Guide

SEO-first walkthrough site for **Royal Smash: Physics Puzzle**, covering Levels 51–370 at [royal-smash.cc](https://royal-smash.cc).

## Development

```bash
npm install
npm run dev
npm run build
```

The site uses Next.js App Router, statically generates every level guide, and publishes dynamic `sitemap.xml` and `robots.txt` routes.
